# cvuts-rpl-diky
Membangun aplikasi web e-commerce interaktif menggunakan metodologi Waterfall. Bertanggung jawab dalam merancang use case diagram, entity-relationship diagram (ERD), serta mengimplementasikan antarmuka pengguna (UI) yang responsif. Sistem ini berhasil mengintegrasikan fitur manajemen keranjang belanja, katalog produk dinamis, simulasi pembayaran.
